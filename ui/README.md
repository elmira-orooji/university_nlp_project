# واژه، رابط محلی پروژه

از ریشهٔ مخزن اجرا کنید:

```powershell
python -m pip install numpy nltk
python ui/server.py
```

سپس http://127.0.0.1:8765 را باز کنید. به نصب Node یا دانلود بسته‌های فونت نیازی نیست.

رابط فارسی و واکنش‌گرا است؛ پردازش داده‌ها برای متن انگلیسی انجام می‌شود. توکن‌سازی، تبدیل حروف، حذف کلمات توقف با فهرست کوتاه محلی و ریشه‌یابی Porter اجرا می‌شوند. طبقه‌بندی مستقیماً تابع Naive Bayes پروژه را فراخوانی می‌کند. بخش جست‌وجو یک پیاده‌سازی مستقل و محدود به ۱۰۰ سند برای پیش‌نمایش تعاملی TF-IDF است و جایگزین تمام حالت‌های بازیابی خط فرمان نیست.

خروجی JSON، کپی، بارگذاری فایل متنی و نمودار فراوانی در دسترس‌اند. داده‌ها محلی پردازش می‌شوند. فونت Vazirmatn همراه مجوز OFL در پوشهٔ fonts قرار دارد. برای حفظ امنیت، سرور فقط روی loopback گوش می‌دهد؛ برای انتشار عمومی طراحی نشده است.

طراحی بصری از [Lemon Design System](https://lemonui.ir/) الهام گرفته است؛ CSS و آیکون‌ها مستقل پیاده‌سازی شده‌اند. حالت روشن و تیره با دکمهٔ بالای صفحه تغییر می‌کند و انتخاب در مرورگر ذخیره می‌شود.

حد مجاز متن و فایل ۲۰۰ هزار بایت است. مهلت انتظار درخواست ۶۰ ثانیه است؛ در صورت پایان انتظار، اجرای جاری روی سرور ممکن است همچنان تکمیل شود. برای جلوگیری از سنگین‌شدن صفحه، حداکثر هزار توکن نمایش داده می‌شود؛ فایل JSON شامل خروجی کامل است.

مدل طبقه‌بندی واژه‌های خارج از واژگان آموزشی را نادیده می‌گیرد و برای متن کاملاً ناشناخته نتیجه صادر نمی‌کند. درصدها برآورد مدل هستند، نه میزان صحت اندازه‌گیری‌شده. مدل و نمایهٔ جست‌وجو تا زمان راه‌اندازی مجدد سرور در حافظه می‌مانند؛ پس از تغییر مجموعه‌داده، سرور را دوباره اجرا کنید.

آزمون‌های رگرسیون از ریشهٔ مخزن اجرا می‌شوند:

```powershell
python -m unittest discover -s ui/tests -v
node --test ui/tests/app.test.cjs
```

آزمون‌های Python سروری موقت روی loopback و یک پوشهٔ موقت ایجاد می‌کنند. آزمون‌های JavaScript رفتارهای ناهم‌زمان رابط را با شبیه‌ساز کوچک DOM بررسی می‌کنند؛ جایگزین بررسی بصری مرورگر نیستند.
